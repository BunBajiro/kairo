decision to retain an existing design. It does not permit an unmeasured defer
to count as completion. Conversely, historical bounded observations and the
unavoidable cost of returning complete requested data are not proof that every
subsystem needs a redesign. Each row needs a source-backed implementation or an
explicit measured disposition before clean RC17 is prepared.

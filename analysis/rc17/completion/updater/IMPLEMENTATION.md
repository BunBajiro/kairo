## Default budgets

| Resource | Default | Rationale / boundary |
|---|---:|---|
| Total conversion wall time | 20 minutes | Finite recoverable ceiling, deliberately far above the historical isolated ~11-second conversion. Current slow-run acceptance remains pending. |
| No measurable conversion progress | 2 minutes | Permits slow I/O; catches blocked input, write or CPU work from the main thread. Total deadline cannot be renewed. |
| Spool lifetime bytes | 768 MiB | Counted before buffering/writing; independent of archive compression ratio. |
| One spool bucket | 64 MiB | Bounds the subsequent whole-bucket `readFile`/decode input. |
| Aggregate pending spool buffers | 8 MiB | Replaces the former implicit per-bucket-buffer accumulation across all buckets. |
| Generated bytes, including manifest | 512 MiB | Enforced while writing, before service manifest validation. |
| Sampled worker external allocations | 256 MiB | Separate from V8 heap; may reject only at checkpoints and cannot be advertised as an RSS/native-memory guarantee. |
| Free-space reserve | 256 MiB | Rechecked before spool/output writes, plus projected write size. |
| Admission space | 2 GiB | Existing 512 MiB maximum downloaded archive + maximum spool + output + reserve. Existing installed generation remains outside that new-work budget and is never predeleted to make room. |

Only lower positive integer limits are accepted by the internal override seam; unknown, zero, non-finite or higher values are rejected. They are not exposed as product settings. Errors explain that installed data is unchanged and a retry can be made after resolving the limit. Conversion failures retain normal failed-build suppression for automatic retries; manual retry remains available.

Warnings retain at most 32 failed path records, with bounded messages, plus the total failure count. Paths are managed basenames rather than user-private absolute locations. If persisting the warning itself fails, the current service retains an actionable warning and logs the failure; persistence on an unwritable/full disk cannot be guaranteed. Future startup/check retries remain possible.

- [loaded-run.mjs](loaded-run.mjs) acquires the existing `/tmp/kairo-rc16-benchmark.lock`, validates a pre-captured source/build manifest and runs four fresh, sequential processes: loaded control, loaded conversion, loaded conversion, loaded control.
- [loaded-child.mjs](loaded-child.mjs) uses the actual supervisor/runtime-child/startKairo/SDE worker path. Only ESI/public transport and the archive delivery source are synthetic/local. The builder is **not injected or replaced**. The normal updater startup trigger is disabled by the adapter so a manual update starts at the same 5-second offset; actual Core collectors, scheduler, HTTP and dashboard/Stream SSE remain running.
- The fixture has two synthetic pilots, 20,000 assets per pilot, 50,000 events, 200 Sessions, eight 100-node Maps and four Stream bindings. HTTP polling exercises state, Universe, Maps and system detail throughout conversion and reconnect. No installed private data is opened.
- Per-generation and per-phase CPU, RSS, heap and main-loop measurements are recorded. Raw HTTP dispatch/completion timings distinguish conversion from the expected restart window. Real output hashes/counts and original-archive digest are verified, and exactly one actual replacement must preserve browser cookie/CSRF and deliver the new revision over reconnected SSE. Unexpected HTTP errors or supervisor rollback fail the lane.
- RSS includes all threads; 100/250 ms memory and phase samples are lower-bound peaks. This protocol lane does not claim browser paint/input or physical OBS performance. Local file streaming excludes Internet download time.
- [inventory-run.mjs](inventory-run.mjs) records warm current inventory cost and source identity for U3. It does not claim a cold-disk measurement or an unimplemented compact-manifest speedup.

The dispatchable workflow is [rc17-updater.yml](../../../../.github/workflows/rc17-updater.yml) (repository root `.github/workflows/rc17-updater.yml`).

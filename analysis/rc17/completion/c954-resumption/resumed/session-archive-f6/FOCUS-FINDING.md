# F6-focus-return: proposed narrow closure

Status: observed baseline defect, open. No application source change has been made. Attempt3 closes the report with trusted Escape and records focus on BODY at 30 loaded cards. Report selection, expanded detail, all 270 events and publication retention passed first. This is not evidence of a cardinality threshold.

`components/kairo/intelligence.tsx` opens `SessionReport` from archive cards, Live report and successful End session. It conditionally mounts the report, keyed by pilot. `components/kairo/session-report.tsx` uses a controlled Radix Dialog with no DialogTrigger and no close-autofocus handler. `components/ui/dialog.tsx` forwards Content props. The installed `@radix-ui/react-dialog/dist/index.mjs` lines154–157 prevent the default restore and then focus `context.triggerRef.current`, which is null here. Current application source should be checked again before integration.

Proposed change: give this report an explicit opener and scoped close-autofocus handler. Capture the event's actual button at each supported report-opening action, including End session before its await. Restore only after a normal report dismissal, only to the same still-connected, enabled opener, and only while SessionsPage remains mounted for the same selected pilot. Suppress restoration for Show on Map/navigation, pilot replacement and teardown. Keep report requests, event pagination, expanded state and archive data unchanged. Avoid a Dialog root for every archive card or a global Dialog behavior change.

Expected validation in a compiled candidate: native Enter opens a chosen archive card; native Escape and close button each restore that exact element, including after a full-prefix refresh with the report open. Live report restores its opener. Successful End session restores the still-mounted recording control after the report closes. Pilot replacement, route navigation and Show on Map must not focus a stale/disconnected or other-pilot opener. Failed requests must not open/restore a report accidentally. Preserve full loaded prefix and expanded 270-event report history. Run relevant existing session/archive semantics, typecheck and fresh build, then the focused compiled scenarios against exact source/build fingerprints. No broad timing rerun is needed for a focus-only fix.

The baseline cardinality run separately records F6-focus-return as an explicit failed observation and remains contractAcceptance=false. Native Find is also unverified because the minimal visible-text control fails in the installed headless Chromium; complete DOM text/visibility and verified trusted Enter remain hard gates. Neither limitation may be reported as closed by diagnostic completion.

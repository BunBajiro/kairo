# F3 narrow snapshot names owner — 8 October 2026

Decision to measure: avoid copying and recursively comparing an unchanged full names map on every selected-pilot snapshot. Baseline is exact `9afa9a7197fa6b5a802e9efdaa322dedf2439150`, the selected c954 continuation. Build #55 / 508 is excluded. This is an isolated proposal; PR #10 remains withdrawn and no clean RC17 acceptance is implied.

## Cause and proposed change

`server/core.mjs:68,271` publishes the complete `namesMap` with snapshots. `rememberNames:76–83` accepts positive numeric IDs with nonempty string names. `components/kairo/dashboard.tsx:187–196` routes selected-pilot snapshots, then uses `retainValue(previous, {...previous,...r.names})`; `resource-state.mjs:5–11` recursively compares the newly copied map. An unrelated wallet event can therefore copy the complete names collection before unchanged identities reach React consumers. `derived-models.mjs:42–59` already avoids rederiving rows for unrelated name changes, but does not remove this owner work.

Deliberately reuse the independently saved `frontend-models/name-merge-trial.patch` on current 9afa. The four-file delta adds `mergeResourceNames`, its declaration, the Dashboard call and tests. The helper scans incoming own enumerable string keys, retaining the previous object when values are unchanged; only a differing/new own key triggers the original spread merge. It preserves partial events, omitted IDs, immutable prior snapshots, rename/addition behavior and prototype safety. The isolated current trial is `kairo-frontend-names-oct8`; the archived old proposal is `recovered-name-merge-trial.patch`. Additional tests extend equivalence and ownership evidence. No timer patch is added: the approved timer fix is already in the current base.

Keep `/state` replacement through `retainValue`, ancillary SSE/state generation fences, selected-pilot routing, server protocol and resource Context unchanged. Initial/recovery state must still be authoritative, including removal of names absent from that state. The helper is for the validated flat string map; it is not a general recursive object merge.

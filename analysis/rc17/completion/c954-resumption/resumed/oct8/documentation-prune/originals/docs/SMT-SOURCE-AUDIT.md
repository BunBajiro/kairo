# SMT public-source and portability audit

Reference: `Slazanger/SMT` commit `6b3b4c6a213a349549ef737c89584fc3f048033b`. Public source documentation and unauthenticated endpoints checked on 25 September 2026. No private ESI or authenticated provider requests were used for this audit.

## Sources and integration decisions

| Capability | SMT implementation | Current contract and Kairo approach |
| --- | --- | --- |
| Thera / Turnur | `EVEData/EveManager.cs` reads EVE-Scout public signatures separately for each hub. | `GET https://api.eve-scout.com/v2/public/signatures?system_name=Thera` and `Turnur` both responded successfully. Public results are fully scanned, unexpired reports; `completed` means scanning completed, not a closed wormhole. Preserve both signatures, expiry, maximum ship size, type and report time. `wh_exits_outward` identifies the type/K162 sides, not one-way travel. Provider cache: 300 seconds. No published numeric request quota found. Kairo respects cache/backoff and never calls a report guaranteed safe or accessible. |
| Metaliminal storms | `EVEData/Storm.cs` scrapes an absolute HTML table XPath from EVE-Scout Rescue; failures return an empty list. | A better documented source now exists: `GET https://api.eve-scout.com/v2/public/observations`, cache 3,600 seconds. Live validation returned eight storms and one space oddity. Preserve `created_at`, `observation_type`, `observed_in_person` and system; these are observations, not present-time confirmation. Kairo retains cached data on failure, adds manual reports with explicit expiry, and labels report age. Its 24-hour stale-report threshold is a local caution threshold, not a provider expiry. |
| Sovereignty / structures / ADM | The pinned SMT version already uses EVEStandard `GetSovereigntySystemsAsync`, while an older manual `/v1/sovereignty/map/` call remains. | Current compatibility contracts use public `/sovereignty/systems`, cache 300 seconds, combining faction/unclaimed/alliance claims, development indices, capital status and sovereignty hub. Older `/sovereignty/map` and `/sovereignty/structures` are absent from the dated current OpenAPI. Kairo derives ownership, hub and development displays from one snapshot. Missing hub vulnerability window means an active campaign; a past window end means overtime. |
| Sovereignty campaigns | SMT polls `ListSovereigntyCampaignsAsync` every 30 seconds. | Public `/sovereignty/campaigns`, provider cache 5 seconds. Campaign and system routes share the `sovereignty` bucket: 600 tokens per 15 minutes; successful requests cost two tokens. Kairo consumes its central cached dataset instead of a second poller. Missing scores remain unknown. |
| Jumpbridge autodiscovery | `LocalCharacter.FindJumpGates` searches visible structures using a naming delimiter, fetches each structure, filters Ansiblex type 35841, then guesses endpoints from names. | Character search requires `esi-search.search_structures.v1`, a minimum three-character query and `categories=structure`; structure lookup requires `esi-universe.read_structures.v1` and character ACL visibility. Both cache for 3,600 seconds. No unauthenticated calls were made. A matching name is a candidate, not proof of connection direction, operation or usable access. Preserve user review and explicit endpoint verification. |
| Public kill feed | Despite its `ZKillRedisQ` class name, this SMT revision already uses R2Z2 sequence files. | Use `https://r2z2.zkillboard.com/ephemeral/sequence.json`, then numbered JSON records. The pointer advances every 51 killmails; records last at least 24 hours and may repeat reprocessed kills. Docs require a descriptive user agent, at most 15 requests/second/IP and at least six seconds after a 404; respect `Retry-After` on 429. Kairo uses opt-in collection, a persisted independent cursor, kill-ID deduplication, bounded serial batches and one-hour/500-record display retention. Personal session collection is separate. |
| Dotlan NPC deltas | SMT requests undocumented `/ajax/npcdelta`, with a browser-style user agent and ETag/modified headers. | The public probe timed out; no supported API contract or numeric quota was established. This does not prove the site is permanently unavailable. Kairo does not depend on this endpoint or copy Dotlan maps. Instead it compares distinct CCP `/universe/system_kills` snapshots, preserving Last-Modified window identity. Those values are rolling one-hour totals; their signed difference is not a count of kills between samples. |
| Static reference markers | SMT CSVs provide market hubs, monuments, POIs, historical ice-bearing systems, observatories, invasion classifications and Jove gates. | Kairo normalizes 2,026 SMT markers against its bundled system IDs, retaining source commit and file hashes, then adds 358 A0 star markers from actual bundled official SDE star type names (2,384 total). Five historical wormhole names are absent from the current atlas and are recorded as unmatched rather than assigned guessed coordinates. All reference markers are historical: no current anomaly availability, ownership, access or resource guarantee. |

Provider outages, malformed responses and expired data must not become a fresh “zero events” result. Cached results retain stale/error context. Replay must not silently overlay current public reports on historical state.

## Primary documentation verified

- [EVE-Scout API UI](https://api.eve-scout.com/ui/) and [OpenAPI](https://api.eve-scout.com/ui/openapi.yaml), version 2.1.55. Its public-endpoint description explicitly permits consumption by third-party EVE tools. Linked operation contracts: [signatures](https://api.eve-scout.com/ui/paths/public/signatures.yaml), [observations](https://api.eve-scout.com/ui/paths/public/observations.yaml), [observation schema](https://api.eve-scout.com/ui/schemas/observation_representation.yaml).
- [Public wormhole types](https://api.eve-scout.com/v2/public/wormholetypes) and their [schema](https://api.eve-scout.com/ui/schemas/public_wormhole.yaml) provide nominal transit mass, total stable mass, regeneration per cycle and maximum lifetime in minutes, cached for 86,400 seconds. These enrich the connection display but do not describe remaining mass. The signature size enum includes `small`, `medium`, `large`, `xlarge`, `capital` and `unknown`.
- [CCP OpenAPI](https://esi.evetech.net/meta/openapi.json), requested with `X-Compatibility-Date: 2026-06-09` and Kairo's `2026-09-04`. An undated request returns an older compatibility contract and should not be treated as the latest schema.
- [CCP ESI rate limiting](https://developers.eveonline.com/docs/services/esi/rate-limiting/): group/user buckets, response headers, token costs and remaining legacy error limits. Public buckets apply per source IP; authenticated buckets combine application and character.
- [Equinox on ESI](https://developers.eveonline.com/blog/equinox-on-esi-structures-sovereignty-and-access-lists), announcing the combined sovereignty systems route and additional authenticated infrastructure routes. Public ownership does not expose all private infrastructure upgrades or ACL rights.
- [zKillboard API documentation](https://zkillboard.com/api/docs/), including R2Z2, response caching, current query limitations and feed duplication. The live pointer returned `Cache-Control: no-store`; consume actual response headers rather than applying a generic daily cache to the pointer.
- [CCP storm description](https://forums.eveonline.com/t/coming-soon-metaliminal-storms-in-nullsec/258511): central system plus one gate jump form the strong area, with two/three-jump weaker areas. Effects can spill into empire space even though the centre remains in nullsec. Kairo uses the real gate graph, not geometric circles.

## Redistribution and platform notes

This is a technical inventory of notices and dependencies, not a legal opinion. SMT's root license is MIT, copyright 2023 Slazanger: retain its copyright and permission notice when redistributing copied code or substantial data portions. Kairo's adapted CSV dataset is covered by its third-party notice. SMT also contains an independently attributed MIT `csDelaunay` implementation, copyright 2014 PouletFrit. That implementation is not part of this port.

SMT's license does not replace licenses for its NuGet dependencies, embedded fonts, EVE artwork or third-party logos. Its Atkinson Hyperlegible font comes from a separately licensed font project; if adopting it, obtain the upstream distribution and notices rather than copying untracked font files. Kairo does not copy SMT's images, logos, font binaries or WPF controls for this integration.

`SMT.csproj` targets `net8.0-windows10.0.17763.0` with WPF and Windows Forms. `EVEData.csproj` targets plain `net8.0`, but its interfaces still need adaptation to Kairo's runtime. The floating overlay uses transparent/topmost WPF windows and `user32.dll` extended-window flags for click-through. NHotkey provides a global overlay toggle. Window placement and shell/explorer integration are Windows-specific. A browser page or OBS browser source cannot reproduce OS-wide topmost, click-through or global hotkeys without a native host. Kairo can provide an in-app HUD and explicit OBS output, while leaving Windows overlay capability separately identified.

SMT opens Dotlan, zKillboard and EVEWho links through the OS shell; it also opens URLs extracted from intel text. Kairo should construct trusted HTTPS destinations from validated IDs/names, render external links explicitly and avoid dispatching arbitrary shell protocols. Clipboard imports should remain explicit user actions, and authenticated EVE waypoint export should never be confused with passive map navigation.
